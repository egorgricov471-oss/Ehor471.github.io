CSS3 Transitions & Animations

CSS Transition is...
A smooth change between CSS property values over a specified period of time
transition-property...
Specifies which CSS property will be animated during a transition
transition-duration...
Specifies how long the transition takes to complete
transition-delay. .
Specifies how long to wait before the transition starts
transition-timing-function...
Controls the speed curve of the transition, such as ease, linear or ease-in
@keyframes is...
A CSS rule that defines the intermediate stages of an animation
animation-iteration-count..
Specifies how many times an animation repeats
transform...
Allows you to rotate, scale, skew or move an element
