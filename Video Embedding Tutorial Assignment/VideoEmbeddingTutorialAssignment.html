How to embed a YouTube video in your website?

1 Find your video on YouTube

Open the video you want to use:

2 Click the Share button

Under the video player, click the Share button. A pop-up window with sharing options will appear:

3 Choose Embed

In the Share window, click the Embed option (the </> icon):

4 Copy the embed code

A box with the <iframe> code appears. Click the Copy button in the bottom right corner of the window:

5 Paste the code into your HTML file

Open your HTML file in a code editor. Paste the code inside the <body> where you want the video to appear. You can change the width and height values if needed:
